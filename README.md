PAULATA

## 1. ¿Cómo va a funcionar?

Se tiene en mente que **Paulata** sea un aplicativo web para la venta de pijamas, en el que los clientes puedan consultar los productos disponibles, conocer sus características y realizar el proceso de compra de una manera sencilla.

El aplicativo contará con un catálogo donde se podrán visualizar las diferentes pijamas disponibles. Los productos estarán elaborados con diferentes tipos de tela, entre ellos **peluche, piel de durazno y poliéster-algodón**.

Cada producto contará con la información necesaria para que el cliente pueda conocerlo antes de realizar su compra, incluyendo sus diferentes tallas y características.

También se busca facilitar el proceso de compra mediante un carrito, en el cual el usuario podrá agregar los productos que desea comprar, revisar los productos seleccionados y eliminar aquellos que ya no quiera adquirir.

## 1.1 ¿Cómo funcionará el proceso de compra?

El usuario podrá ingresar al aplicativo y navegar por el catálogo de productos disponibles.

Una vez encuentre una pijama que sea de su interés, podrá consultar su información y seleccionar la talla correspondiente.

Después podrá agregar el producto al carrito de compras.

Dentro del carrito, el usuario podrá:

- Consultar los productos seleccionados.
- Agregar productos.
- Eliminar productos.
- Revisar los productos antes de realizar el pedido.

Además, el aplicativo contará con opciones para **filtrar los productos**, permitiendo al usuario encontrar más fácilmente las pijamas que está buscando.

También existirá una sección con información sobre las **tallas disponibles**, con el objetivo de ayudar al cliente a seleccionar la talla adecuada.

## 1.2 Funcionalidades principales

El aplicativo contará con las siguientes funcionalidades:

- Catálogo de productos.
- Visualización de información de cada producto.
- Filtrado de productos.
- Selección de tallas.
- Carrito de compras.
- Agregar productos al carrito.
- Eliminar productos del carrito.
- Información de tallas.
- Botón de contacto para facilitar la comunicación con el cliente.
